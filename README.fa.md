# t3code-rtl

پشتیبانی راست‌چین (RTL) برای T3 Code. پیام‌های فارسی و عربی، پیام‌های داخل صف، عنوان ترد و کارت پرسش بالای کامپوزر راست‌چین می‌شوند و با فونت آراد نمایش داده می‌شوند. بلوک کد، خروجی ترمینال، دیف و سایدبار چپ‌چین می‌مانند.

![یک ترد فارسی با وصله‌ی اعمال‌شده](https://raw.githubusercontent.com/farhadeidi/t3code-rtl/main/media/preview.png)

## چه چیزی عوض می‌شود

تنها بلوک‌هایی که دست‌کم یک حرف فارسی یا عربی دارند تغییر می‌کنند؛ بقیه دقیقاً همان‌طور که بودند می‌مانند.

- پاراگراف، آیتم لیست، سرتیتر و سلول جدول داخل پیام‌های چت
- پیامی که در صف منتظر ارسال است، و عنوان ترد در هدر چت
- کارت پرسش و درخواست‌های تأیید بالای کامپوزر؛ گزینه‌ی فارسی آینه می‌شود و شماره‌ی میان‌بر سمت چپ می‌نشیند
- ورودی کامپوزر جهت خودش را از چیزی که تایپ می‌کنی می‌گیرد. تنها تغییر آنجا این است که چیپ فایل پیوست دیگر جهت پیام فارسی را تعیین نمی‌کند

خط عربی تشخیص داده می‌شود، که فارسی، عربی، دری، اردو و پشتو را پوشش می‌دهد. عبری تشخیص داده نمی‌شود.

## نصب و اجرا

</div>

<div dir="ltr">

```sh
npx t3code-rtl
```

</div>

<div dir="rtl">

اجرای اول، T3 Code را پیدا می‌کند، می‌پرسد آپدیت‌ها چطور مدیریت شوند، وصله را اعمال می‌کند و انتخابت را به خاطر می‌سپارد. بعد از آن T3 Code را دوباره باز کن. برای نصب دائمی دستور، `npm install -g t3code-rtl` را اجرا کن و بعد `t3code-rtl` را صدا بزن.

به Node.js نسخه ۲۰ یا بالاتر نیاز دارد، به‌همراه یکی از نصب‌های T3 Code: اپ دسکتاپ macOS، اپ دسکتاپ لینوکس، پکیج npm با نام `t3`، یا اپ ویندوز (که هنوز تست نشده).

## دستورها

</div>

<div dir="ltr">

```sh
npx t3code-rtl                 # منوی تعاملی
npx t3code-rtl patch           # اعمال وصله
npx t3code-rtl unpatch         # برداشتن وصله و تنظیمات
npx t3code-rtl status          # وضعیت اپ‌های شناسایی‌شده و نسخه‌ها
npx t3code-rtl doctor          # اطلاعات تشخیصی کامل
npx t3code-rtl update          # آپدیت با Homebrew و اعمال دوباره‌ی وصله (macOS)
```

## نکته‌های مهم

- این ابزار فایل‌هایی داخل بسته‌ی نصب‌شده‌ی T3 Code را تغییر می‌دهد. هر آپدیت T3 Code وصله را پاک می‌کند، پس بعد از آپدیت `npx t3code-rtl patch` را دوباره اجرا کن.
- در macOS اگر T3 Code را با Homebrew نصب کرده باشی، حالت managed را انتخاب کن؛ آنجا `t3code-rtl update` هم اپ را آپدیت می‌کند و هم وصله را برمی‌گرداند.
- `npx t3code-rtl unpatch` همه‌چیز را برمی‌گرداند. نصب دوباره‌ی T3 Code هم بسته را بایت‌به‌بایت به حالت اول برمی‌گرداند.
- پیام‌ها، تنظیمات و ترافیک شبکه‌ی اپ دست نمی‌خورد. تغییر فقط در لایه‌ی نمایش است.
- این یک ابزار غیررسمی است و وابستگی‌ای به پروژه‌ی T3 Code ندارد. مشکلات را در [issue tracker](https://github.com/farhadeidi/t3code-rtl/issues) گزارش کن.
